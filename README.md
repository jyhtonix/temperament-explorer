# temperament-explorer
Temperament Self-Reflection Test

I've created the standalone HTML web app for your students. You can download it and run it locally without a paid API key or external service.

What's included?
- 20 multiple-choice questions covering study habits, teamwork, communication, decision-making, stress and problem-solving.
- Four temperament profiles: Choleric, Sanguine, Phlegmatic and Melancholic.
- Automatic scoring, ranked results, progress tracking, and support for tied scores.
- Explanations of potential strengths, blind spots and self-reflection questions.
- Mobile-friendly layout, back and next navigation, and printing or saving results as PDF.
- No account, API key, or server required.

Accuracy checks and limitations
I've structured the question bank so that each question has exactly four answer options, with one option mapped to each temperament. The scoring counts the selected responses and displays the four totals, which should add up to 20 when all questions are answered.

One important academic distinction: the traditional four-temperament model is not a clinically validated personality assessment. The web app therefore presents results as self-reflection rather than a psychological diagnosis or definitive personality classification. The questions and scoring logic have been checked for consistency, but the assessment has not been psychometrically validated with a student sample.

How to use it
1. Download the HTML file.
2. Open it in Chrome, Edge or another modern browser.
3. Share the file with your students, or deploy it on a static hosting platform such as Vercel.
4. Ask students to answer based on their usual behaviour rather than the answers they think are most desirable.

For classroom use, I'd recommend describing this as a Temperament Self-Reflection Test rather than a formal psychological test.
